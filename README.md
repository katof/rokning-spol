# Spøl til Rokning 1a og 1b

Spøl til stóran skerm í flokshølinum, eitt ella tvey til hvønn kapittul í *Rokning 1* (uppgávubók 1a og 1b).

Startsíðan liggur á Snar og letur spølini upp herifrá:
https://snardev.ctrl.fo/fileadmin/user_upload/TEMA_-_KT/Rokning_sp%C3%B8l/0_Sp%C3%B8l_til_Rokning_1a_og_1b.html

Spølini liggja í `rokning-1/`. Hvørt spæl er ein fíla, har myndirnar eru innbygdar.

Framgongdin verður goymd í kaganum. Skifta tit kaga ella teldu, so eru øll framstig vekk.
