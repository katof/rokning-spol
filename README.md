# Spøl til Rokning 1a og 1b

Spøl til stóran skerm í flokshølinum, eitt ella tvey til ymsu evnini í Rokning.

Startsíðan er á Snar.

## Einsamøll við hús – Mín fyrsta lesing

Mappan `einsamoll-vid-hus/` hevur uppgávusíðurnar til lesibókina *Einsamøll við hús* (ein HTML-fíla fyri hvørja síðu, felags `lesing.css` og `lesing.js`, myndir í `img/`). Forsíðan liggur á Snar.
