Stig 5 · CSS

Uppseting

Lær at gera kassar við rammum, rundum hornum og skugga.

Steyp: Byggimeistari
Mál
  • Tú brúkar div og class til at skipa síðuna í kassar.
  • Tú skilir munin á padding og margin.
  • Tú gert rammur, rund horn og skugga.
  • Tú setir kassar lið um lið við display: flex.
ByggBrúka vitlíkiDeil og ger betriHygg afturum

Hugsa tær, at hvørt element á síðuni hevur ein kassa rundan um seg. Við CSS kanst tú geva honum lit, rammu og pláss. Tú kanst eisini savna fleiri element inni í einum <div> og geva tí eitt navn við class. Eitur tað class="kassi", velur tú tað í CSS við .kassi.

Luft inni og uttan

padding ger pláss inni í kassanum, millum innihaldið og rammuna. margin ger pláss uttan um kassan. Royn at broyta bæði tølini í kotuni og hygg, hvat hendir.

Lið um lið

Kassar standa vanliga hvør undir øðrum. Vilt tú seta teir lið um lið, leggur tú teir í ein felags kassa og skrivar display: flex í CSS-regluna. Við gap ásetir tú frástøðuna millum kassarnar.

Kassar lið um lið<style> .rað { display: flex; gap: 16px; } .kassi { background-color: white; border: 3px solid black; border-radius: 16px; padding: 16px; box-shadow: 6px 6px 0 black; } </style> <div class="rað"> <div class="kassi">Fyrsti kassi</div> <div class="kassi">Annar kassi</div> </div>

Orðabók

<div>Ein kassi uttan serliga merking. Brúktur til at skipa síðuna.
classEitt navn, tú gevur elementi, so tú kanst velja tað í CSS. Dømi: class="kassi" → .kassi { }
paddingLuft inni í kassanum.
marginLuft uttan um kassan.
borderRamman. Dømi: border: 2px solid black;
border-radiusRund horn. Dømi: border-radius: 12px;
box-shadowSkuggi. Dømi: box-shadow: 4px 4px 10px gray;
display: flexSetir kassarnar inni í elementinum lið um lið.
gapLuft millum kassarnar í einum flex-kassa.
max-widthMesta breidd. Dømi: max-width: 600px;
Prei: Royn at skriva * { outline: 1px solid red; } ovast í CSS-kotuni. Tá sært tú allar kassarnar á síðuni! Tak tað burtur aftur, tá ið tú ert liðug/ur.
