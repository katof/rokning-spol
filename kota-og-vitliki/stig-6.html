Stig 6 · JavaScript

Nú skal síðan gera okkurt

Ger knøttar, sum broyta tekst og lit, tá ið tú trýstir á teir.

Steyp: Forritari
Mál
  • Tú veitst, hvat JavaScript kann, sum HTML og CSS ikki kunnu.
  • Tú gert ein knøtt, sum setir eina funktión í gongd.
  • Tú finnur eitt element við getElementById og broytir tekstin.
  • Tú lesur eitt villuboð og roynir umaftur.
ByggBrúka vitlíkiDeil og ger betriHygg afturum

HTML skipar innihaldið, og CSS broytir útsjóndina. Við JavaScript kanst tú fáa síðuna at gera okkurt. Ein knøttur kann til dømis broyta tekstin ella bakgrundslitin, tá ið tú trýstir á hann. JavaScript er eitt forritanarmál, sum nógvar heimasíður og netspøl brúka.

Trý stig

  1. Ger ein knøtt í HTML: <button onclick="heilsa()">Trýst her</button>. Við onclick sigur tú, at funktiónin heilsa() skal byrja, tá ið onkur trýstir á knøttin.
  2. Gev tekstinum eitt navn við id: <p id="svar"></p>. Tú eigur bara at brúka sama id eina ferð á hvørjari síðu.
  3. Skriva funktiónina inni í <script>. Hon finnur tekstbrotið við document.getElementById("svar") og broytir tekstin við .textContent.
Knøttur og funktión<button onclick="heilsa()">Trýst her</button> <p id="svar"></p> <script> function heilsa() { document.getElementById("svar").textContent = "Hey! Tú hevur trýst á knøttin!"; } </script>

Villur eru vanligar

Í JavaScript mást tú stava nøvnini neyvt. getElementById endar við stórum I og lítlum d – tað er ikki tað sama sum eitt lítið l. Ein gloymd klombra kann eisini gera, at kotan ikki virkar. Fært tú villuboð, so les tað, finn viðkomandi linju og royn umaftur. Tað er ein vanligur partur av at læra at forrita.

Ein tilvildarlig upplýsing

Vilt tú hava ein knøtt, sum vísir eina nýggja upplýsing hvørja ferð? Tú kanst seta upplýsingarnar í ein lista [ ] og brúka Math.random() til at velja eina av teimum:

Tilvildarligt valvar fakta = ["Lundin kann kava 60 metrar.", "Seyðurin hevur ein maga við fýra pørtum.", "Grindahvalurin er ein delfin."]; var tal = Math.floor(Math.random() * fakta.length); document.getElementById("svar").textContent = fakta[tal];
