Tín egna heimasíða

Nú hevur tú lært nógv. Brúka tað, tú dugir, til at gera tína egnu heimasíðu um eitt evni, tú velur.

Steyp: Heimasíðusmiður
Mál
  • Tú gert eina heila heimasíðu við HTML, CSS og JavaScript.
  • Tú brúkar vitlíki sum hjálp og kannar úrslitið.
  • Teksturin er á góðum føroyskum og er tín egni.
  • Tú tekur síðuna niður sum fílu og leggur hana fram.
ByggHygg aftan fyriBrúka vitlíkiDeil og ger betri

Vel eitt evni, tú hevur áhuga fyri: eitt djór, ein ítrótt, eitt spæl, ein film, eitt stað ella tónleik. Tú kanst eisini gera eina síðu um teg sjálva ella sjálvan, men skriva ikki persónligar upplýsingar, sum ikki skulu vera almennar. Vel tín egna tekst, tínar litir og tíni hugskot.

Soleiðis arbeiðir tú

  1. Legg eina ætlan. Hvat skal síðan eita? Hvat vilt tú siga frá? Hvat skal knøtturin gera?
  2. Byrja við HTML. Tú hevur longu eina einfalda grundkotu í ritlinum niðanfyri.
  3. Fá hjálp frá vitlíki, um tú vilt. Brúka boðsmiðjuna í stigi 7. Les svarið, vel tað, tú skilir, og set tað inn.
  4. Kanna. Trýst á Koyr ofta. Riggar alt? Les villuboðini.
  5. Set tín egna dám á síðuna. Broyt minst fimm ting, til dømis tekst, litir, skrift, kassar og knøttin.
  6. Tak fíluna niður og lat hana upp í kaganum heima. Legg síðuna fram fyri flokkinum.

Tá ið tú leggur fram

Svara hesum spurningum: Hvat evni valdi tú? Hvat var lættast? Hvat var trupult? Hjálpti vitlíki tær – og hvat máttu tú rætta? Hvat dámar tær best við síðuni? Hvat lærdi tú um HTML, CSS og JavaScript?

Deil og ger betri – tvey og tvey

Áðrenn tú leggur fram, vísir tú síðuna fyri einum øðrum næmingi, og tit geva hvør øðrum viðmerkingar. Spyr:

  • Riggar síðan? Er okkurt, sum ikki virkar?
  • Er greitt at síggja, hvat tú sjálv ella sjálvur skrivaði, og hvat kom frá vitlíkinum?
  • Kanst tú greiða frá, hvat knøtturin ger – uttan at hyggja í kotuna?
  • Eitt, sum er gott – og eitt, sum kundi verið betri.

Ger so síðuna betri, áðrenn tú leggur hana fram. Tað er seinasta rørslan í hjólinum – og so byrjar tað umaftur.

Hvat vit hyggja eftir

  • Tekniskur skilningur: kanst tú greiða frá, hvat kotan ger?
  • Kritisk nýtsla av vitlíki: kannaði og broytti tú tað, vitlíkið gav tær – og merkti tú, hvat er títt?
  • Samstarv og deiling: gav tú og fekst tú viðmerkingar, og gjørdi tú síðuna betri aftaná?

Síðan skal hava

  • rættan bygnað við title
  • eina h1 og minst eina h2
  • minst tvey tekstbrot
  • ein lista við minst trimum punktum
  • eina mynd við alt-teksti
  • CSS við minst trimum reglum
  • ein knøtt, sum ger okkurt við JavaScript
  • føroyskan tekst, sum tú sjálv ella sjálvur hevur orðað
  • viðmerkingar, sum siga, hvat er títt, og hvat kom frá vitlíkinum
Ikki gera hetta: Kopiera ikki alt frá vitlíkinum uttan at lesa tað. Brúka ikki ov nógvar litir í senn. Lat ikki danskan tekst standa. Lat ikki villur standa, um ritilin vísir tær.
Goymsla: Kotan verður goymd í kaganum á hesi eindini. Vilt tú arbeiða víðari á aðrari teldu, so tak fíluna niður og set kotuna inn aftur.
